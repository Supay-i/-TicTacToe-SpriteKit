# Крестики-нолики (TicTacToe)

iOS-игра «Крестики-нолики», реализованная на языке Swift с использованием игрового фреймворка SpriteKit.

## Описание
Классическая логическая игра для двух игроков на поле 3×3 или увеличенном поле 5×5 (победа — 4 метки подряд). Поддерживается игра «на одном устройстве» и игра против компьютера.

## Режимы игры
- Игрок против игрока
- Игрок против компьютера — три уровня сложности ИИ (лёгкий / средний / сложный), реализовано алгоритмом minimax с альфа-бета отсечением

## Технологии
- Swift 5
- SpriteKit
- Xcode 15+
